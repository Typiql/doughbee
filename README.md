## About

**doughbee** is a modern, welcoming landing page for a small sourdough bakery. It features a warm, bakery-inspired aesthetic and a responsive layout designed for mobile phones, tablets, laptops, and desktop screens.

*Note: Sample photography and menu details are placeholders and should be replaced with actual bakery photos, products, prices, and contact information before launch.*

## Features

- 📱 Responsive, mobile-first design
- 🍞 Single-page artisan bakery landing page
- 🎨 Separate HTML, CSS, and JavaScript files
- 🧩 BEM (Block, Element, Modifier) CSS naming convention
- ♿ Accessibility and reduced-motion considerations
- 🚀 Free static hosting through GitHub Pages

## Built With

## Getting Started

### Run Locally

1. Clone or download this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same directory.
3. Open `index.html` in your web browser.

Alternatively, use Visual Studio Code with the Live Server extension for local development.

## BEM Naming Convention

CSS classes follow the **Block–Element–Modifier (BEM)** methodology where practical.

| Type | Example |
|---|---|
| Block | `.hero` |
| Element | `.hero__title` |
| Modifier | `.button--primary` |

This naming convention helps keep styles organized, reusable, and maintainable.

## Customization

- **Content:** Edit `index.html` to update text, product descriptions, links, and contact information.
- **Styling:** Edit `style.css` to adjust colors, typography, spacing, and responsive breakpoints.
- **Functionality:** Edit `script.js` to modify interactive behavior.
- **Photography:** Replace placeholder images with original bread photography or images you have permission to use. Optimize image sizes for performance and provide descriptive alt text.
